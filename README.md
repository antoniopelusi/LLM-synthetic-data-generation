# LLM-synthetic-data-generation

The project follows a three-step process to evaluate the quality of synthetic tabular data generated by large language models. It was tested using the [pointe77/credit-card-transaction](https://huggingface.co/datasets/pointe77/credit-card-transaction) dataset and the following models:

- [Qwen/Qwen2.5-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct)
- [mistralai/Mistral-7B-Instruct-v0.3](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.3)

The pipeline is fully config-driven and can be adapted to any tabular dataset and any causal language model supported by Hugging Face.

Each model is evaluated across multiple generation strategies, both with and without Differential Privacy (DP):

- Zero-shot In-Context Learning
- Few-shot In-Context Learning (1, 5, 10 records)
- LoRA Fine-Tuning (10% and 50% of the dataset)

## Steps

1. [**Dataset Analysis**](analysis/analysis.ipynb): Analyzes the original dataset to extract schema, distributions, and patterns. This information is used to engineer the system prompts required for effective generation.

2. [**Synthetic Data Generation**](generation/generation.ipynb): Runs the generation process for a given model and strategy configuration.

3. [**Synthetic Data Comparison**](comparison/comparison.ipynb): Compares synthetic results against the original dataset using statistical metrics and qualitative inspection.

## Setup

Run the initial setup once:
```sh
make setup
```
This will:
- Remove any previous virtual environment (`.venv`)
- Create a new virtual environment and install dependencies from `requirements.txt`
- Register the `.venv` kernel for Jupyter

Activate the virtual environment prior to executing any Python scripts using the following command:
```sh
source .venv/bin/activate
```

If it's a Jupyter notebook, run it using the `.venv` kernel.

## Usage

All three notebooks are driven by a single JSON config file in `configs/`. The config is built incrementally across steps.

### Step 1 — Analysis

Create a config file in `configs/` (e.g. `configs/my_experiment.json`) with the following fields:

```json
{
  "dataset_name": "pointe77/credit-card-transaction",
  "dataset_seed": 42,
  "dataset_dir": "../dataset",
  "output_dir": "../outputs",
  "datasets": [...],
  "required_fields": { ... },
  "nullable_fields": [...],
  "original_dataset": "cct_ft_100pct.json",

  "drop_columns": [...],
  "str_fillna_columns": [...],
  "int_to_str_columns": [...],
  "str_to_int_columns": [],
  "str_to_float_columns": [],
  "float_to_int_columns": [],

  "num_cols": [...],
  "cat_cols": [...],
  "nn_cols": [...],

  "label_analysis": { "enabled": true, "label_col": "...", "amount_col": "...", "category_col": "..." },
  "geo_analysis":   { "enabled": true, "lat": "...", "lon": "...", "merch_lat": "...", "merch_lon": "..." },
  "temporal_analysis": { "enabled": true, "unix_time_col": "...", "label_col": "..." }
}
```

Set `CONFIG_FILE` at the top of `analysis/analysis.ipynb` and run the notebook.

### Step 2 — Generation

Add the following fields to the same config file:

```json
{
  "model": "...",
  "strategy": "lora",
  "prompt": { "system": "...", "user": "...", "assistant": "..." },
  "dataset": "...",

  "seed": 0,
  "num_samples": 10000,
  "max_new_tokens": 1024,
  "batch_size": 8,
  "max_grad_norm": 1,
  "temperature": 0.8,
  "top_p": 0.95,
  "repetition_penalty": 1.05,
  "lora_r": 8,
  "lora_alpha": 16,
  "lora_dropout": 0.05,
  "learning_rate": 0.0001,
  "epochs": 1,
  "dp": false
}
```

For Differential Privacy, add `"dp": true` and the following:
```json
{
  "dp_epsilon": 1,
  "dp_delta": 1e-6,
  "dp_grad_sample_mode": "hooks",
  "dp_accountant": "rdp"
}
```

Set `CONFIG_FILE` at the top of `generation/generation.ipynb` and run the notebook.

### Step 3 — Comparison

No additional fields needed. The config is already complete after Step 2.

Set `CONFIG_FILE` at the top of `comparison/comparison.ipynb` and run the notebook.

> Ready-to-use config examples for all tested experiments are available in `configs/`.
